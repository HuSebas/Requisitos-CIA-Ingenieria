## C-01 · Compra urgente frente a control previo

| | |
|---|---|
| Condición de ganancia A | **Residente de obra:** comprar de inmediato cuando la actividad no puede esperar (E-02 #6). |
| Condición de ganancia B | **Gerente de obra y contador:** que ningún gasto quede sin autorizar ni sin soporte (E-02 #9, #10). |
| Conflicto | Exigir aprobación previa detiene la obra; permitir la compra libre deja el gasto fuera de control. |
| Opciones | 1) Bloquear toda compra sin aprobación. 2) Permitir la compra urgente con registro inmediato y legalización posterior. 3) Dejar la caja menor fuera del sistema. |
| Acuerdo | Opción 2, con tope y plazo (PD-03, PD-04). El gasto se descuenta el mismo día y queda «por legalizar». |
| Requisitos | RF-012, RF-013, RF-014, RF-015 |

## C-02 · Ver todo en un solo lugar frente a presupuesto reservado

| | |
|---|---|
| Condición de ganancia A | **Gerente de obra y administradora:** una vista única con avance, gasto y saldo (E-02 #4). |
| Condición de ganancia B | **Gerente general:** que no todos vean el presupuesto completo (E-02 #5). |
| Conflicto | Una vista única para todos expone información reservada. |
| Opciones | 1) Vista única sin restricción. 2) La misma vista filtrada por rol. 3) Vistas separadas por cargo. |
| Acuerdo | Opción 2: una sola vista cuyo contenido depende del rol (PD-05). |
| Requisitos | RF-019, RF-036, RF-037, RNF-006 |

## C-03 · Datos completos frente a registro mínimo

| | |
|---|---|
| Condición de ganancia A | **Administradora de proyectos:** que cada registro llegue completo y trazable (E-01 #1, #2). |
| Condición de ganancia B | **Residente de obra:** que registrar no le quite más tiempo que hoy (E-01 #11, #12). |
| Conflicto | Cada campo adicional mejora el control y alarga el registro en obra. |
| Opciones | 1) Formulario completo obligatorio. 2) Mínimo obligatorio en campo; el resto lo completa administración. 3) Texto libre. |
| Acuerdo | Opción 2: máximo 8 campos obligatorios en campo y meta de 15 minutos por corte. |
| Requisitos | RNF-001, RNF-002, RF-016 |

## C-04 · Pedidos duplicados: el cuestionario frente a las entrevistas

| | |
|---|---|
| Posición A | **Cuestionario preliminar:** los pedidos duplicados son frecuentes. |
| Posición B | **Administradora y gerente de obra:** no recuerdan ninguno (E-01 #5; E-02 #11). |
| Conflicto | Especificar una alerta de duplicados sin evidencia del problema. |
| Opciones | 1) Especificarla. 2) Descartarla hasta tener evidencia. |
| Acuerdo | Opción 2. RC-10 queda descartado y la pregunta se dirige al contador. |
| Requisitos | Ninguno |

## C-05 · Bloquear una compra sin saldo frente a dejar la decisión al aprobador

| | |
|---|---|
| Condición de ganancia A | **Gerente general:** que el gasto no supere el presupuesto sin autorización. |
| Condición de ganancia B | **Gerente de obra:** poder aprobar un exceso justificado sin que el sistema lo impida (E-02 #8). |
| Conflicto | Un bloqueo automático impide excesos legítimos que hoy se aprueban. |
| Opciones | 1) El sistema rechaza toda solicitud sin saldo. 2) El sistema informa el exceso y enruta al nivel que corresponde. |
| Acuerdo | Opción 2: el sistema muestra el exceso y aplica la tabla de decisión; solo el gerente general aprueba lo que supera imprevistos. |
| Requisitos | RF-003, RF-006, RN-04, RN-05 |

## C-06 · Mano de obra y subcontratos frente al plazo

| | |
|---|---|
| Condición de ganancia A | **Gerente de obra:** controlar también mano de obra y subcontratos, que pesan en el presupuesto (E-02 #14). |
| Condición de ganancia B | **Equipo:** entregar el SRS en la fecha acordada con procesos efectivamente levantados. |
| Conflicto | El proceso no se levantó y no hay tiempo para hacerlo con el contador y los residentes. |
| Opciones | 1) Incluirlo con supuestos. 2) Dejarlo fuera y registrarlo como trabajo futuro. |
| Acuerdo | Opción 2. RC-19 queda fuera de alcance y pasa al informe final. |
| Requisitos | Ninguno |
