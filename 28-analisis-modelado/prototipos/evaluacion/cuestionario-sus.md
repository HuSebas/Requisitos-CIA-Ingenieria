# Cuestionario SUS

Escala de usabilidad del sistema (System Usability Scale, Brooke, 1996). Se responde justo después de usar el prototipo, sin pensarlo demasiado.

| | |

Marque de 1 (totalmente en desacuerdo) a 5 (totalmente de acuerdo).

| N.º | Afirmación | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|

| 2 | La aplicación me pareció innecesariamente compleja. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 3 | La aplicación me pareció fácil de usar. | ☐ | ☐ | ☐ | ☐ | ☐ |

| 5 | Las funciones de la aplicación están bien integradas. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 6 | Encontré demasiada inconsistencia en la aplicación. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 7 | Creo que la mayoría de las personas aprendería a usarla muy rápido. | ☐ | ☐ | ☐ | ☐ | ☐ |

| 10 | Tuve que aprender muchas cosas antes de poder usarla. | ☐ | ☐ | ☐ | ☐ | ☐ |

## Cómo se calcula

1. En las afirmaciones impares (1, 3, 5, 7, 9): respuesta menos 1.
2. En las pares (2, 4, 6, 8, 10): 5 menos la respuesta.
3. Se suman los diez valores y el total se multiplica por 2,5. El resultado va de 0 a 100.

Un puntaje de 68 se considera el promedio; la meta del proyecto es 68 o más (US-05).

**Ejemplo.** Respuestas 4, 2, 4, 1, 4, 2, 5, 2, 4, 2. Impares: 3 + 3 + 3 + 4 + 3 = 16. Pares: 3 + 4 + 3 + 3 + 3 = 16. Total: 32 × 2,5 = 80.
